# Мембрана дома (краткая редакция зерна; канон — repo-doctrine)

- **1 смысл = 1 репо.** Копии смысла — не живут; история живёт в тегах и летописи.
- **Живой репо = CI + тесты.** Красный гейт — не работа, а недоделка.
- **НИКАКИХ НОТИФИКАЦИЙ.** Тревога живёт в issue с label `alarm:*` (протокол
  A-HUSH: открыл — молчи), разрядка — фактом зелёного такта (судья или страж).
- **Пруф в коммитах:** каждый коммит отвечает «Поработал? Сделал? Убрал за собой».
- **Тесты только добавляются** (храповик). Пин actions по SHA.
- **Манифест/пломба генерятся, а не пишутся** — ручная правка = красный.
- **Ключ — клетка:** права только на своё помещение, короткий срок.
- **Лимит — душа дома:** вызовы API куплены фактом, не привычкой.

Мировые практики — сырьё; принципы — канон №27 repo-doctrine.
